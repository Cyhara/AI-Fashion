# StyleAI

StyleAI is an AI-powered fashion styling prototype. Its static frontend helps users explore fashion styles, chat with a demo stylist, and upload model and clothing images for outfit generation. A FastAPI backend handles image uploads and integrates with Claid AI.

The current sign-in, sign-up, and account deletion flows are browser-only demos, not real authentication. The product roadmap tracks the work required for secure accounts and a production-ready release.
